Ques3:-Describe how a browser requests and displays a web page from a web server.

Ans:-1.User Action:-The user enters the URL in the browser.
2.DNS Lookup:-The browser finds the IP address of the website’s server.
3.HTTP Request: The browser sends a request to the server.
4.Server Processing: The web server fetches the requested file (HTML, CSS, JS) and data from the database if needed.
5.Response Sent: The server sends the data back to the browser.
6.Rendering: The browser interprets the HTML, CSS, and JavaScript to display the page to the user.

Ques8:-Explain the difference between static and dynamic websites. Provide an example of each.

Ans:-Static webiste:-The content is fixed and the same for every visitor unless manually updated by a developer. It have fixed content
delivered to all users, built with HTML, CSS, and JavaScript.
Generally faster because pages are pre-built and delivered directly from the server. 
Complexity: Simpler to build and maintain, with lower hosting costs. 

Example:- A portfolio site made with only HTML & CSS.

Dynamic Website:- Content can change based on user, time, location, or other factors, providing a personalized and interactive experience. 
It can generate content in real-time using server-side scripting languages and databases, allowing for personalized experiences.
Slower to load because content is generated on the server for each request. 
Complexity: More complex to build and requires more resources and maintenance. 

Example:-YouTube, where content changes based on the user.
